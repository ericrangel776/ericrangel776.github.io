Model-graded evals catch what unit tests can't

Spent this week tightening the eval suite for a document-extraction pipeline. Schema validation catches malformed JSON, but it says nothing about whether the extracted values are actually correct. Added a second pass where a grading model compares extracted fields against source text and flags low-confidence matches for human review. Caught several silent field-mapping errors that every existing test was blind to.

ENTRY_004.LOG
2026.07.30 // 21:02

Chunking strategy matters more than the embedding model

Swapped embedding models twice this month chasing better retrieval accuracy before realizing the real issue was upstream: fixed-size chunking was splitting answers across chunk boundaries. Moved to a structure-aware splitter that respects headings and list boundaries, and retrieval quality improved more from that one change than from any model swap.

Agents are easier to debug when they narrate

Rebuilt a multi-step LCEL agent to log its intermediate reasoning to a structured trace instead of just the final output. When something goes wrong three steps into a chain, staring at the final answer tells you nothing. The trace turns debugging from guesswork into just reading a log.
